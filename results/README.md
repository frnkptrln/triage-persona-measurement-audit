# Result artifacts

`raw/` contains one `gzip(json)` artifact per model. Each archive contains the
exact instrument snapshot, raw model completions, parser route, record-level
metadata, archived summary, and run manifest.

`derived/` is fully regenerated by `scripts/analyze_multimodel.py`. The script
recomputes every summary from raw records, checks agreement with the archived
tables, applies the prospective smoke-stop interpretation, and writes the
cross-model tables and publication figure.

The instrument uses fictional scenarios. Raw outputs are research records, not
clinical recommendations.
